DOMARO WEBSITE V5

WHAT V5 ADDS
- Checkout now sends orders to Supabase.
- Orders are stored centrally in the DOMARO database.
- Order number is generated by the database.
- Product price and shipping total are calculated/validated server-side.
- Client submits only product IDs + quantities.
- Cash on Delivery remains the payment method.
- Flat shipping remains 80 EGP.

SECURITY
- Frontend uses only the Supabase publishable key.
- No database password or service-role key is included in the website.
- Direct anonymous reads/writes to orders are blocked.
- Order creation is allowed only through the place_order database function.
- Product prices are read from the database inside the function, so a customer cannot change the price in the browser and submit it as trusted data.
